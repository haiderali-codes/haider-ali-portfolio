# Haider Ali Portfolio

Production-ready portfolio for Haider Ali, built with Next.js 15, TypeScript, Tailwind CSS and lightweight CSS/IntersectionObserver animations.

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

## Deployment

The project is Vercel-ready. Connect the GitHub repository to Vercel and set:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.vercel.app
```

Every push to the production branch can trigger a Vercel deployment automatically once the repository is connected.
